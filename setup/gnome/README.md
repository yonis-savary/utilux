# GNOME keyboard shortcuts

Custom keyboard shortcuts registered through `gsettings`.

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> | Launch the web browser |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd> | Launch a terminal |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>E</kbd> | Open the home folder |

## Apply

```bash
~/utilux/setup/gnome/apply-config
```

An existing shortcut with the same identifier is overwritten. `utilux-setup` also lists it in its menu on GNOME.
